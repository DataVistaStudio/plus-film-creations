# Security Policy — Plus Film Creations

This public repository is a **project information reference**, not an invitation to test the production website or access private participant information. The complete website source, private film-submission system, account records and deployment credentials are **not published here**.

## Responsible disclosure

Please send potential security concerns privately to **info@plusfilmcreations.org**, with the subject **Security — Plus Film Creations**.

Describe the affected page or feature and provide concise, non-invasive reproduction details. Do **not** include passwords, access tokens, personal records, unpublished films or another person's data in your report. Please do not publish vulnerability details in a public GitHub issue.

No security bounty, fixed response time or supported-version commitment is promised.

## Safe repository scope

- Do not commit secrets, OAuth credentials, private keys, member records, submissions, session files, backups, server configuration or production databases.
- Do not distribute copyrighted film excerpts, portraits, photographs, fonts, press-book originals or other assets without the relevant rights.
- Any proposal to publish source code requires a **separate review of the entire Git history**, secret exposure, privacy obligations and redistribution rights.
- A source-document update or GitHub commit does **not** authorize deployment, testing private accounts, opening public registration, or changing production infrastructure.
- Festival event dates, screening venues, rules and FilmFreeway links must be verified against the [official website](https://plusfilmcreations.org/).

## العربية

للإبلاغ عن مشكلة أمنية، يرجى التواصل بسرّية عبر **info@plusfilmcreations.org**. لا تنشر الثغرات علنًا ولا تُرسل كلمات المرور أو بيانات المشاركين أو الأفلام الخاصة. هذا المستودع مرجع للمشروع وليس تصريحًا باختبار الأنظمة الخاصة أو استخدامها.

## Français
