# Contributing — Plus Film Creations

Thank you for your interest in Plus Film Creations. This is an **owner-managed public project reference**, not an announced open-source code release. Contributions to the website, festival and creative work require review and approval.

## Public repository scope

This repository provides official project information and selected public documentation. It does **not** publish the production website source, account infrastructure, participant records, private film submissions, original unreleased footage or licensed media.

For project proposals or corrections, use **info@plusfilmcreations.org**. Please do not upload private data or copyrighted materials to a public GitHub issue or pull request.

## Content accuracy

- Cite the original authorized source for festival names, organizer roles, partners, venues and event details.
- Use the official [Plus Film Creations website](https://plusfilmcreations.org/) as the public reference.
- The [SLD Film Festival page](https://plusfilmcreations.org/?page=festival&lang=en) and [press materials](https://plusfilmcreations.org/?page=press&lang=en) show published information; do not invent film selections, jury members, past editions, submission deadlines or screening venues.
- Never copy branding, photographs, team lists or venue information from other festivals (including Beirut Shorts) as though they belonged to SLD.
- An official FilmFreeway submission link should appear **only after that specific festival URL and submission conditions are verified**.

## Project quality and publishing

Website content serves Arabic, English and French readers. Proposed changes should preserve established branding and accessibility, explain source provenance, specify affected languages and obtain relevant copyright permissions.

Every production website release requires separate owner authorization, focused QA and rollback. A GitHub commit is **not** a deployment approval.

## العربية

نرحّب بالمقترحات المتعلقة بمشروع **بلس فيلم كرييشنز**، مع ضرورة توثيق المعلومات واحترام حقوق الأفلام والصور والهوية البصرية. لا ترفع بيانات المشاركين أو الملفات الخاصة. تُعتمد التعديلات والنشرات بعد مراجعة الجهة المسؤولة، ولا يعني نشر مستند في GitHub نشره على الموقع.

## Français

Les contributions doivent respecter les sources officielles, les droits des films et des images, ainsi que les versions arabe, anglaise et française du site. Ne publiez aucune donnée privée ni œuvre non autorisée. Toute modification du site nécessite une validation distincte.
